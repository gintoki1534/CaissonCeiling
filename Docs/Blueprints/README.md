# Blueprints

这里存放按蓝图拆分后的可读文档。

用途：

1. 给后续开发者快速阅读当前蓝图真实接线。
2. 给 AI 提供稳定、明确、可引用的蓝图知识来源。

来源：

1. 原始数据来自 `Docs/BlueprintExports/` 下对应蓝图的 `json` 文件。
2. 本目录文档由导出脚本和 AI 协同整理生成。

更新入口：

1. `Docs/generate_blueprint_docs.ps1`
2. `Tools/README.md`

阅读建议：

1. 先看本目录的 `md`，快速了解蓝图职责和关键链路。
2. 如果需要确认更细的节点结构，再回看 `Docs/BlueprintExports/` 下对应 `json`。
